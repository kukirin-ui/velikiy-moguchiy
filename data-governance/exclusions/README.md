# Исключение каналов из обучения

Модель чтения по губам (`lipread/`) дообучается на публичных видео YouTube. Владелец канала может попросить, чтобы
его видео больше не использовались: для этого есть шаблон issue
[«Исключить мои видео»](https://github.com/zigansh1n/velikiy-moguchiy/issues/new?template=exclusion.yml).

## Что происходит после запроса

1. Мейнтейнер проверяет, что запрос пришёл от владельца канала (способ подтверждения описан в шаблоне).
2. Идентификатор канала добавляется в [`channels.tsv`](channels.tsv) отдельным PR со ссылкой на issue в описании PR,
   а не в самом журнале.
3. Ссылку на канал в issue мейнтейнер убирает правкой, issue закрывается.
4. Видео канала исключаются из данных **следующей версии модели**. Уже выпущенные версии не меняются: из готовых весов
   нельзя удалить вклад отдельных видео.

В журнале хранится **только идентификатор канала** и дата исключения. Ни названия канала, ни имени владельца, ни
причины запроса, ни ссылки на issue в нём нет.

## Формат `channels.tsv`

Текст UTF-8, одна строка на канал, два поля через табуляцию:

```
UCxxxxxxxxxxxxxxxxxxxxxx	2026-10-14
```

- идентификатор канала — `UC` и ещё 22 символа (поле `channel_id` у yt-dlp, часть адреса
  `youtube.com/channel/UC…`); адрес вида `@имя` сначала переводится в идентификатор;
- дата — день, с которого канал исключён, в формате `ГГГГ-ММ-ДД`;
- строки, начинающиеся с `#`, и пустые строки пропускаются; повтор идентификатора — ошибка.

Формат проверяется в CI (`exclusions.py --check`, workflow «Data governance»).

## Как журнал читает конвейер данных

```python
import sys; sys.path.insert(0, "data-governance/exclusions")
from exclusions import excluded_channel_ids

excluded = excluded_channel_ids()
```

Журнал применяется в трёх местах:

- **задания участникам** «Помочь обучить» (`federated/`): ролики таких каналов не попадают в пул заданий
  (`space/build_pool.py`), сервер приёма их не выдаёт, а клиент пропускает ролик, если yt-dlp при скачивании назвал
  канал из журнала; без журнала задание не идёт. Это подключено;
- **сбор** в `lipread/`: ролик, у которого `channel_id` в журнале, не скачивается (как каналы из `channel_skip.txt`) —
  пока не подключено;
- **сборка набора для обучения** в `lipread/`: клипы таких каналов выбрасываются из манифеста перед каждой новой
  версией модели, даже если были скачаны раньше, — пока не подключено.

Журнал хранит только идентификаторы каналов, которые попросили об исключении. Списки собранных видео и каналов в
репозиторий не публикуются.
