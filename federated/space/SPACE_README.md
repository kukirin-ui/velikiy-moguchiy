# «Великий & Могучий»: обучение силами участников

Сюда приложение участника отправляет обновление весов модели чтения по губам после обучения у себя на компьютере.
Видео, звук и кадры лица сюда не попадают: только обновление весов (safetensors) и числа о вкладе.

Код этого сервера и правила: [github.com/zigansh1n/velikiy-moguchiy](https://github.com/zigansh1n/velikiy-moguchiy/tree/main/federated).
Папка собрана автоматически, правки вносятся в репозиторий на GitHub.
