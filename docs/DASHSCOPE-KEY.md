# Ключ DashScope

Русскую речь «Великий & Могучий» распознаёт моделями Qwen через DashScope, сервис Alibaba Cloud. Звук уходит туда с
вашим ключом, и платите за распознавание вы сами, по тарифам Alibaba Cloud. Ключ хранится только у вас.

## Как получить ключ

1. Зарегистрируйтесь в международной версии Alibaba Cloud: [alibabacloud.com](https://www.alibabacloud.com).
2. Откройте консоль Model Studio: [modelstudio.console.alibabacloud.com](https://modelstudio.console.alibabacloud.com),
   раздел «API Key», и создайте ключ.
3. Скопируйте ключ целиком (он начинается с `sk-`).
4. На Mac: «Настройки → Распознавание», поле «Ключи DashScope», затем «Проверить ключ».

## Регион

Ключ работает только в регионе, где создан, и у каждого региона свой адрес:

| Где создан ключ | Адрес (`asr.qwen.url`) |
|---|---|
| Международная консоль (Сингапур) | `wss://dashscope-intl.aliyuncs.com/api-ws/v1/realtime` |
| Китайская консоль ([bailian.console.aliyun.com](https://bailian.console.aliyun.com)) | `wss://dashscope.aliyuncs.com/api-ws/v1/realtime` |

Новая установка приложения настроена на международный регион. Уже настроенное приложение адрес не меняет.
Если ключ из другого региона, «Проверить ключ» скажет об этом и предложит переключить адрес.

## Что значат ошибки

- **«Ключ не подходит»** — ключ скопирован не целиком, удалён в консоли или создан в другом регионе.
- **«Закончился баланс ключа»** — на счёте Alibaba Cloud нет денег или закончился бесплатный лимит.
- **«Слишком много запросов»** — сервис временно ограничил ключ; подождите минуту. Можно указать несколько ключей, по
  одному в строке: при отказе одного приложение берёт следующий.
- **«Нет доступа к модели»** — модель недоступна этому ключу или региону; выберите другую модель в настройках.

Без ключа Mac-приложение предлагает распознавание прямо на компьютере (оно хуже облачного).
