Сейчас приложение для Windows — это архив `VelikiyMoguchiy-Windows-x64.zip` без подписи: SmartScreen
предупреждает при первом запуске, а автозапуск и удаление пользователь настраивает сам
([`windows/README.md`](https://github.com/zigansh1n/velikiy-moguchiy/blob/main/windows/README.md)).

**Что сделать.**

1. Установщик на пользователя, без прав администратора: ярлык в меню «Пуск», автозапуск по желанию, нормальное
   удаление через «Параметры → Приложения». Формат на ваш выбор (MSIX, WiX, Inno Setup); обоснуйте выбор в PR.
2. Сборку установщика в `.github/workflows/build-windows.yml` рядом с zip и добавление в релиз.
3. Подпись кода как необязательный шаг: если в репозитории заданы секреты сертификата, установщик и exe
   подписываются, иначе сборка остаётся без подписи и CI зелёный. Для открытых проектов есть бесплатные варианты
   (например, SignPath Foundation) — опишите, что подходит.
4. По желанию — манифест для `winget`.

**Как проверить.** Установка, запуск, автозапуск после перезагрузки и удаление на чистой Windows 10 и 11; после
удаления не остаётся файлов программы (настройки пользователя можно оставить).
