В начале [`README.md`](https://github.com/zigansh1n/velikiy-moguchiy/blob/main/README.md) не хватает живой картинки: как человек говорит, а текст появляется в
обычном приложении.

**Что сделать.** Записать на Mac 10–15 секунд: зажата клавиша диктовки, сказана фраза по-русски, текст со знаками
препинания появился, например, в «Заметках». Сохранить как GIF или MP4 не больше 5 МБ в `design/readme/` и вставить
в README под баннером.

**Требования.**

- В кадре нет лиц, имён, почты, чужих переписок и вашего ключа в настройках.
- Сказанная фраза — ваша собственная, не цитата из песни или фильма.
- Тёмная и светлая темы — на ваш выбор, главное, чтобы текст читался.

**Как проверить.** `python3 tools/privacy_guard.py` проходит, README на GitHub показывает анимацию.
