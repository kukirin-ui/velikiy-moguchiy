---
title: Проверка ссылок в документации в CI
labels: good first issue
---

В репозитории много README и документов со ссылками друг на друга и на внешние сайты. Когда файл переезжает, ссылка
тихо ломается.

**Что сделать.** Workflow `.github/workflows/links.yml`, который на каждом PR, меняющем `*.md`, проверяет ссылки
(например, [lychee](https://github.com/lycheeverse/lychee-action)) и раз в неделю проверяет весь репозиторий.
Внешние сайты иногда отвечают ошибкой без причины, поэтому в PR достаточно проверять ссылки внутри репозитория, а
внешние — только в еженедельном запуске. Пропуски, если они нужны, — в одном файле настроек с комментарием, почему.

**Как проверить.** PR с намеренно сломанной ссылкой падает, обычный PR — нет. Найденные битые ссылки можно
починить в том же PR.
