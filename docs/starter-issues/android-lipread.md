Клавиатура для Android ([`android/`](https://github.com/zigansh1n/velikiy-moguchiy/tree/main/android/)) умеет диктовку голосом. Режима «губы», как на Mac,
у неё нет: модель MultiVSR слишком большая для телефона, а своя лёгкая модель — пока пункт дорожной карты в
[`README.md`](https://github.com/zigansh1n/velikiy-moguchiy/blob/main/README.md).

**Что выяснить и сделать.**

1. Может ли клавиатура (`InputMethodService`) снимать фронтальной камерой, пока она открыта: какие разрешения
   нужны и какие ограничения Android 11+ на камеру вне активного окна мешают. Итог — короткая заметка в
   `android/LIPREAD.md`.
2. Прототип за флагом в настройках: запись короткого клипа без звука и отправка на сервис чтения по губам на
   компьютере пользователя в той же сети ([`lipread/lips_service.py`](https://github.com/zigansh1n/velikiy-moguchiy/blob/main/lipread/lips_service.py)).
   Сейчас сервис слушает только 127.0.0.1 и принимает путь к файлу, поэтому ему понадобится приём самого видео и
   явное включение доступа из сети.
3. Оценка, что нужно, чтобы модель работала на самом телефоне: размер, скорость, формат (ONNX, TFLite).

**Как проверить.** Заметка с ответами на вопросы и, если прототип получился, описание проверки в PR (без видео
с лицами). Видео с камеры не уходит никуда, кроме компьютера, который указал сам пользователь.
